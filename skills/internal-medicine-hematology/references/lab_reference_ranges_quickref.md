# Clinical Laboratory Reference Ranges & Critical Values

A rapid clinical reference sheet of standard adult reference values, units, and critical alert thresholds.

---

## 1. Hematology & Coagulation

| Parameter | Standard Adult Reference Range | Critical Alert Threshold | Clinical Implications |
| :--- | :--- | :--- | :--- |
| **Hemoglobin (Hb)** | Men: 135–175 g/L<br>Women: 120–160 g/L | $< 70\text{ g/L}$ (Transfusion threshold)<br>$> 200\text{ g/L}$ (Polycythemia vera) | Tissue hypoxia, active hemorrhage, hyperviscosity. |
| **Platelets (PLT)** | 150–450 x 10^9 / L | $< 20–30\text{ x }10^9\text{ / L}$<br>$> 1000\text{ x }10^9\text{ / L}$ | Spontaneous mucosal/intracranial bleeding risk; thrombosis risk. |
| **White Blood Cells (WBC)**| 4.0–10.0 x 10^9 / L | $< 1.0\text{ x }10^9\text{ / L}$ (Agranulocytosis)<br>$> 30.0\text{ x }10^9\text{ / L}$ (Leukemoid / Leukemia) | Febrile neutropenia protocol, systemic sepsis, hematologic malignancy. |
| **INR (Prothrombin Time)** | 0.8–1.2 (baseline)<br>2.0–3.0 (Warfarin target) | $> 4.5–5.0$ (High hemorrhage risk) | Reverse with Vitamin K / Prothrombin Complex Concentrate (PCC) if bleeding. |
| **D-Dimer** | $< 0.5\text{ mg/L FEU}$ | Age-adjusted cutoff: $\text{Age } \times 0.01\text{ mg/L}$ for patients $> 50\text{ years}$ | High negative predictive value for DVT / PE exclusion. |

## 2. Serum Chemistry & Electrolytes

| Parameter | Standard Adult Reference Range | Critical Alert Threshold | Clinical Implications |
| :--- | :--- | :--- | :--- |
| **Potassium ($K^+$)** | **3.5–5.1 mmol/L** | **$< 2.8\text{ mmol/L}$** (Hypokalemia)<br>**$> 6.0\text{ mmol/L}$** (Hyperkalemia) | High risk of ventricular fibrillation, asystole, peaked T waves, muscle paralysis. |
| **Sodium ($Na^+$)** | **136–145 mmol/L** | $< 120\text{ mmol/L}$ (Cerebral edema)<br>$> 160\text{ mmol/L}$ (Hyperosmolar coma) | Correct slowly ($< 8–10\text{ mmol/L/24h}$) to prevent Osmotic Demyelination Syndrome. |
| **Serum Creatinine** | Men: 62–106 umol/L<br>Women: 44–84 umol/L | Acute doubling from baseline | Acute Kidney Injury (KDIGO criteria), pre-renal hypoperfusion, nephrotoxic drugs. |
| **eGFR (CKD-EPI)** | $\ge 90\text{ mL/min/1.73m}^2$ | $< 15\text{ mL/min/1.73m}^2$ | End-Stage Renal Disease (ESRD) - nephrology referral for renal replacement therapy. |
| **Total Bilirubin** | $< 21\ \mu\text{mol/L}$ | $> 50\ \mu\text{mol/L}$ | Clinical icterus/jaundice; evaluate direct vs indirect fraction. |
| **C-Reactive Protein (CRP)**| $< 5.0\text{ mg/L}$ | $> 100\text{ mg/L}$ | Severe acute bacterial infection, sepsis, deep soft tissue abscess. |
