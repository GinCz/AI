# Acute Stroke Triage & NIHSS Clinical Scale Reference

A rapid reference for stroke recognition, hyperacute timelines, and the NIH Stroke Scale (NIHSS) assessment.

---

## 1. Acute Stroke Time-Critical Flowsheet

```
[Symptom Onset / Last Known Well Time T=0]
    |
    +--> [0 to 4.5 Hours Window]
    |       |-- Non-contrast Head CT (Rule out Hemorrhage, calculate ASPECTS score)
    |       |-- Blood glucose check (Rule out hypoglycemia mimic: glucose < 3.0 mmol/L)
    |       \-- If eligible -> Intravenous Thrombolysis (IVT: rtPA / Alteplase 0.9 mg/kg)
    |
    \--> [0 to 24 Hours Window]
            |-- CT Angiography (CTA) from aortic arch to vertex
            |-- Identify Large Vessel Occlusion (LVO: ICA, MCA-M1/M2, Basilar)
            \-- If eligible -> Endovascular Mechanical Thrombectomy (EVT)
```

---

## 2. NIH Stroke Scale (NIHSS) Key Domains

Total score ranges from **0 to 42** (Scores $> 20–25$ indicate severe stroke):

| Item | Assessment Area | Scoring Range | Clinical Significance |
| :--- | :--- | :--- | :--- |
| **1a** | Level of Consciousness (LOC) | 0 (Alert) to 3 (Coma) | Overall cerebral cortical suppression. |
| **1b-1c** | LOC Questions & Commands | 0 (Normal) to 2 (Neither correct) | Basic receptive and cognitive processing. |
| **2** | Horizontal Eye Movements | 0 (Normal) to 2 (Forced deviation) | Conjugate gaze palsy (eyes look toward cortical lesion). |
| **3** | Visual Fields | 0 (Normal) to 3 (Bilateral hemianopia) | Homonymous hemianopia (optic radiation damage). |
| **4** | Facial Palsy | 0 (Normal) to 3 (Complete paralysis) | Central (lower face only) vs peripheral palsy. |
| **5a-5b** | Motor Arm (Left / Right) | 0 (No drift 10s) to 4 (No movement) | Corticospinal pyramidal tract motor weakness. |
| **6a-6b** | Motor Leg (Left / Right) | 0 (No drift 5s) to 4 (No movement) | Lower limb motor cortex / internal capsule deficit. |
| **7** | Limb Ataxia | 0 (Absent) to 2 (Present in 2 limbs) | Finger-to-nose and heel-to-shin (cerebellar lesion). |
| **8** | Sensory Loss | 0 (Normal) to 2 (Severe/Total loss) | Pinprick sensation in all four extremities. |
| **9** | Best Language (Aphasia) | 0 (Normal) to 3 (Mute / Global aphasia) | Naming objects, describing Cookie Theft picture. |
| **10** | Dysarthria | 0 (Normal) to 2 (Severe / Unintelligible) | Motor speech clarity (repeating "Mama, Tip-Top, 50-50"). |
| **11** | Extinction & Inattention (Neglect) | 0 (Normal) to 2 (Profound hemi-inattention)| Sensory hemi-neglect (parietal lobe lesion). |
